## Documentation maintenance rules

- Prefer concise summaries here and detailed explanations in the relevant guide.
- Keep relative links valid when moving files.
- Update docs in the same pull request as behavior, workflow, release, or licensing changes.
- Mark plans as planned and tests as unverified unless evidence confirms execution.
- Record external data sources, retrieval/version details where practical, and applicable license/attribution obligations before redistribution.
