# Support

Vendora is an early-stage open-source project. Features and interfaces can change, and debug preview builds are not intended for production business data.

## Choose the right channel

- **Bug report:** [Open a bug report](https://github.com/MasfikurDev/vendora-android/issues/new?template=bug_report.yml). Include the app version or commit, device/Android version when relevant, steps to reproduce, expected behavior, and observed behavior.
- **Feature request:** [Propose an improvement](https://github.com/MasfikurDev/vendora-android/issues/new?template=feature_request.yml). Explain the user problem and the offline/data-integrity constraints involved.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md). Do not post exploitable details publicly.
- **Code contributions:** read [CONTRIBUTING.md](CONTRIBUTING.md).

## Before opening an issue

1. Search existing issues and pull requests for a duplicate.
2. Use a current build and include its release tag or commit SHA if known.
3. Share minimal reproduction steps and relevant logs with secrets removed.
4. Never attach real shop/customer records, access tokens, passwords, signing keys, or private API credentials.

## Support expectations

Support is best-effort. There is no paid support, guaranteed response time, or production incident SLA. Please do not rely on Vendora preview builds for critical business operations or regulatory compliance.
